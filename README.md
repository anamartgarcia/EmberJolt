# EmberJolt

EmberJolt optimizes high-performance computing with just-in-time compilation and dynamic resource allocation, leveraging an orchestrator.

EmberJolt is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/EmberJolt.git`
2. `cd EmberJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

EmberJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
